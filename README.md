# PDF Studio Pro — קובצי התקנה ועדכונים

כאן נמצאים **רק קובצי ההתקנה** של התוכנה PDF Studio Pro, כדי שכל המחשבים במשרד יוכלו להתקין אותה ולהתעדכן בלחיצה אחת.

## מה יש כאן
- **אין כאן קוד מקור.** קוד התוכנה שמור במקום פרטי ונפרד, ולא מתפרסם.
- בכל גרסה (בעמוד "Releases" בצד ימין) יש שלושה קבצים:
  - קובץ ההתקנה (`...-setup.exe`);
  - קובץ החתימה שלו (`.sig`) — התוכנה בודקת אותו לפני כל עדכון, וכך קובץ שמישהו שינה לא יותקן;
  - קובץ `latest.json` — "כרטיס הגרסה" שהתוכנה קוראת כדי לדעת אם יש גרסה חדשה.

## התקנה במחשב חדש
1. בעמוד הזה, בצד ימין, לוחצים על **Releases** ובוחרים את הגרסה העליונה (Latest).
2. מורידים את הקובץ שמסתיים ב־`-setup.exe`.
3. מפעילים אותו. אם Windows מציג חלון כחול ("Windows protected your PC") — לוחצים "מידע נוסף" ואז "הפעל בכל זאת".
4. ההתקנה לא צריכה הרשאות מנהל ומותקנת למשתמש הנוכחי.

## עדכון
התוכנה בודקת לבד אם יש גרסה חדשה כמה שניות אחרי שהיא נפתחת. כשיש — מופיעה הודעה, ולחיצה על "התקן והפעל מחדש" מעדכנת אותה.
אפשר גם לבדוק ידנית: הגדרות ← עדכונים ← "בדוק עכשיו".
